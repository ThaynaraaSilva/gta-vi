# GTA VI — Landing Page

Landing page desenvolvida com foco em desenvolvimento Front-End, 
reproduzindo uma experiência visual inspirada na divulgação de 
Grand Theft Auto VI.

## Sobre o projeto

Este projeto foi desenvolvido como parte dos meus estudos em 
Desenvolvimento Web, com o objetivo de praticar estruturação de 
interfaces, estilização, responsividade, animações e organização 
de código.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- GSAP
- ScrollTrigger
- Google Fonts

## Funcionalidades

- Landing page responsiva
- Vídeo de apresentação
- Seção de história
- Seção de trailer
- Navegação por links
- Animações e efeitos visuais

  
- Layout adaptado para diferentes tamanhos de tela
